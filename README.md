# PHONOTEK — Web Demo

Демо для технического и дизайн-ревью: https://vladislavsavin543.github.io/phonotek-demo/

В репозитории находятся только собранные статические файлы интерфейса. История и исходники основного приватного проекта сюда не перенесены.

- 12 вымышленных альбомов, собственные геометрические обложки и синтетические треклисты.
- Home, Archive/Gallery, поиск, оценки, заметки и Sonic Map.
- Изменения хранятся только в отдельной локальной базе этого демо в браузере.
- Сервер, облачная синхронизация и реальные музыкальные провайдеры не подключены. Соответствующие сетевые действия в статическом демо недоступны.
- Личная библиотека, реальные заметки, .env, токены и backup-файлы не включены.

Это демонстрационная сборка, а не размещённый production API. Не импортируйте личные данные в публичное демо.
